# Interface

The operational dashboard retains the source's month navigation, paired Postpaid and Broadband summaries, trend, segment breakdowns and history table. Managers get a team table and agent selector above that dashboard. Dense tables scroll horizontally on small screens. Forms keep visible labels and keyboard focus. Authentication uses a separate two column desktop layout, collapsing to one column on mobile.

Colors: primary #88377f, hover #6b2565, background #f6f7f8, text #22252b, secondary text #636773, borders #e1e3e7. Semantic red #bc2424, amber #946000, green #26733e. System Segoe UI text serves the operational interface; numeric columns use tabular numerals. Panels use 10px corners and 18px padding. Buttons use 7px corners and at least 38px height, with 30px compact table actions.

Use the official Zain Bahrain logo from the recorded source in README. Keep credentials and configuration details outside agent workflows. Setup failures use a clear unavailable state. No sample sales are displayed as live data.
